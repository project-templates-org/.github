# Support

- **Bug or feature request** → open an issue using the matching form in the relevant repository.
- **How do I use the templates?** → read the [project-template docs](https://github.com/project-templates-org/project-template/tree/main/docs).
- **Security issue** → see [SECURITY.md](SECURITY.md). Never post it publicly.
- **Anything else** → open an issue in [project-templates-org/.github](https://github.com/project-templates-org/.github/issues) — maintainers triage it there.
