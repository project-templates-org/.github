# Code of conduct

This org follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and constructive; critique code, not people.
- No harassment, discrimination or personal attacks.
- Assume good intent and help newcomers.
